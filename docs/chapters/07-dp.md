# 动态规划

动态规划（DP）把**多阶段决策**问题拆成可递推的子问题，用**状态**记录历史决策，用**转移方程**表达"从子问题构造原问题"。它是算法竞赛中分值最大、套路最深的题型。

## 1. DP 三要素

1. **状态**：描述子问题的变量 `dp[i] / dp[i][j]`
2. **转移方程**：状态之间的递推关系
3. **初始条件 / 边界**：`dp[0] / dp[1]` 等基础值
4. **（可选）优化**：滚动数组、单调队列、状态压缩

判断是否用 DP 的三个特征：

- **最优子结构**：问题的最优解包含子问题的最优解
- **重叠子问题**：递归解法会重复计算同一子问题
- **无后效性**：未来决策只与"现在状态"有关，与"如何到达"无关

## 2. 入门：斐波那契

```javascript
// 暴力递归 O(2^n)
function fib(n) {
  if (n < 2) return n
  return fib(n - 1) + fib(n - 2)
}

// 记忆化 O(n)
function fibMemo(n, memo = {}) {
  if (n < 2) return n
  if (memo[n] != null) return memo[n]
  return (memo[n] = fibMemo(n - 1, memo) + fibMemo(n - 2, memo))
}

// 迭代 O(n) 空间 O(1)
function fibIter(n) {
  if (n < 2) return n
  let a = 0, b = 1
  for (let i = 2; i <= n; i++) [a, b] = [b, a + b]
  return b
}
```

记忆化是"自顶向下"，迭代是"自底向上"。两者等价。

## 3. 经典模型

### 3.1 0/1 背包

`n` 个物品，第 `i` 个重 `w[i]`、价值 `v[i]`，背包容量 `W`，每个物品**最多选一次**：

```javascript
function knapsack01(n, W, weights, values) {
  const dp = new Array(W + 1).fill(0)
  for (let i = 0; i < n; i++) {
    for (let j = W; j >= weights[i]; j--) {  // 倒序避免重复选
      dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i])
    }
  }
  return dp[W]
}
```

时间 O(nW)，空间 O(W)（滚动数组）。

### 3.2 完全背包

每个物品**可选无限次**——内层循环改为正序：

```javascript
for (let i = 0; i < n; i++) {
  for (let j = weights[i]; j <= W; j++) {  // 正序
    dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i])
  }
}
```

### 3.3 最长公共子序列（LCS）

```javascript
function lcs(s1, s2) {
  const m = s1.length, n = s2.length
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0))
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (s1[i - 1] === s2[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1
      else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1])
    }
  }
  return dp[m][n]
}
```

时间 O(mn)，空间 O(mn)，可滚动数组优化到 O(n)。

### 3.4 编辑距离

```javascript
function editDistance(word1, word2) {
  const m = word1.length, n = word2.length
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0))
  for (let i = 0; i <= m; i++) dp[i][0] = i
  for (let j = 0; j <= n; j++) dp[0][j] = j
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1]
      } else {
        dp[i][j] = 1 + Math.min(
          dp[i - 1][j],      // 删除
          dp[i][j - 1],      // 插入
          dp[i - 1][j - 1]   // 替换
        )
      }
    }
  }
  return dp[m][n]
}
```

### 3.5 最长递增子序列（LIS）

```javascript
function lis(nums) {
  const tails = []  // tails[i] = 长度为 i+1 的 LIS 最小末尾
  for (const x of nums) {
    let lo = 0, hi = tails.length
    while (lo < hi) {
      const m = (lo + hi) >> 1
      if (tails[m] < x) lo = m + 1
      else hi = m
    }
    tails[lo] = x
  }
  return tails.length
}
```

时间 O(n log n)——经典"DP + 二分"优化。

## 4. 区间 DP

区间 DP 在**子串 / 子序列**问题中常见，状态 `dp[i][j]` 表示区间 `[i, j]` 上的最优解。

```javascript
// 最长回文子序列
function longestPalindromeSubseq(s) {
  const n = s.length
  const dp = Array.from({ length: n }, () => new Array(n).fill(0))
  for (let i = 0; i < n; i++) dp[i][i] = 1
  for (let len = 2; len <= n; len++) {
    for (let i = 0; i + len <= n; i++) {
      const j = i + len - 1
      if (s[i] === s[j]) dp[i][j] = (len === 2 ? 0 : dp[i + 1][j - 1]) + 2
      else dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1])
    }
  }
  return dp[0][n - 1]
}
```

## 5. 状态压缩 DP

当状态维度是布尔集合（如"哪些列被占用"），用位掩码压缩：

```javascript
// 例：n×n 棋盘放 n 个互不攻击的皇后
function totalNQueens(n) {
  let count = 0
  function dfs(row, cols, diag1, diag2) {
    if (row === n) { count++; return }
    for (let col = 0; col < n; col++) {
      const d1 = row - col + n, d2 = row + col
      if ((cols & (1 << col)) || (diag1 & (1 << d1)) || (diag2 & (1 << d2))) continue
      dfs(row + 1, cols | (1 << col), diag1 | (1 << d1), diag2 | (1 << d2))
    }
  }
  dfs(0, 0, 0, 0)
  return count
}
```

## 6. 优化技巧

| 优化 | 场景 | 收益 |
|------|------|------|
| 滚动数组 | dp[i] 只依赖前 1-2 行 | 空间 O(n) → O(1) |
| 状态压缩 | 状态用 0/1 表示 | 空间 O(2ⁿ) |
| 单调队列 | 滑动窗口 DP | 时间 O(n) |
| 四边形不等式 | 区间 DP | 时间 O(n³) → O(n²) |
| 决策单调性 | 多种 DP | 显著提速 |

## 7. 套路总结

- **计数型**：求方案数 / 路径数 → `dp[i] = sum / product`
- **最值型**：求最长 / 最短 / 最多 → `dp[i] = min / max`
- **存在型**：判断能否达到 → `dp[i] = OR`
- **路径型**：网格 / 迷宫 → `dp[i][j]` 表示到 (i,j) 的方案

## 8. 调试技巧

1. **打印 dp 数组**：在小数据上手动验证递推
2. **先写暴力递归**：再改成记忆化，最后改迭代
3. **检查边界**：`dp[0]` / `dp[1]` 是否正确
4. **检查循环顺序**：0/1 背包倒序、完全背包正序
